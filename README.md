# P・SPO 店舗マップ＆CarPlayナビ (P・SPO Navigator)

> **P・SPO（ピースポ）公式の店舗検索が使いづらい悩みを解消！**  
> 愛媛県内85店舗（全90店舗）を美しく高速なマップで一覧化し、**クランクベンチ**や**スタディroom**のある店舗をワンタップで探せて、そのまま**Apple Maps / CarPlayでカーナビ案内を開始**できるオリジナルWebアプリケーションです。

---

## 🌟 主な機能・特徴

### 1. 🚗 スマホで開いてCarPlayでナビができる（Apple Maps連携）
- 各店舗カードやマップピンに、特大の**「🍎 Appleマップでナビ（CarPlay対応）」**ボタンを常時配置。
- iPhoneのSafari等でタップするだけで、即座にiOS標準「マップ」アプリが起動し、目的地への自動車ルート案内が始まります。
- 車の**CarPlay**にiPhoneを有線またはワイヤレス接続していれば、**車載ディスプレイにそのまま案内画面が投影**されます！
- ※ Google Mapsでの案内ボタンも併載しています。

### 2. 🏋️‍♂️ クランクベンチ（クランチベンチ）設置店舗を一発検索
- 指定の多機能自重腹筋ベンチ（`img_machine_20.jpg`）が導入されている店舗（愛媛県内外 **21店舗**）をワンタップで絞り込み表示。
- スポットライトバナーと店舗カードに対象マシン画像つきでハイライト表示されます。
- **導入店舗例**: 松山空港通り店、松山中央通り店、松山湯渡店、松山本町店、松山小坂店、松山南斎院店、松山砥部店、松山鷹子店、内子店、大洲店、西条東予店、新居浜松原店、マリエール今治店、ワールドプラザ店、伊予店、サウナ大街道店など。

### 3. 📖 スタディroom（自習室・コワーキング）設置店舗を一発検索
- 24時間利用可能な集中個別ブース・Wi-Fi・電源・WEB個室を備えたSTUDY ROOMおよび自習カフェ併設店舗（**45店舗**）をワンタップで絞り込み。
- **導入店舗例**: STUDY ROOM 1, STUDY ROOM 2, 松大前店, 東温店, ジム&スタディカフェ大街道店, 千舟町店, 市駅南店, 愛大前店, 平和通り店, 姫原店, 三津店, 鷹子店, 西条武丈店, 新居浜松原店など。

### 4. 🗺️ 愛媛県内全域対応インタラクティブマップ
- **Leaflet.js** を採用した超軽量＆滑らかな地図表示。
- 松山市中心部、東温・砥部、西条・新居浜、今治・しまなみ、大洲・八幡浜・宇和島までピンポイント網羅。
- アイコン・カラー（🏋️ オレンジ=クランクベンチ、📖 ブルー=スタディ、♨️ パープル=サウナ/温泉、💪 グリーン=ジム）で一目で判別可能。
- 「愛媛県全体」「松山市内」へのワンタップ表示切り替え機能。

### 5. 📍 GPS現在地連動 ＆ 距離順ソート
- 「📍 現在地」ボタンを押すだけで、今いる場所から最も近いP・SPO店舗を自動計算・近い順にソート。

### 6. 🔍 複合フィルター＆キーワード即時検索
- エリア別（松山、東温、砥部、今治、西条・新居浜、大洲・南予、県外）
- 設備・サービス別（セルフエステ・脱毛、サウナ・温泉・岩盤浴、シミュレーションゴルフ、カフェ、有人店舗）

## 📱 CarPlayでの利用手順

1. iPhoneのSafariで本アプリ（`index.html` または GitHub Pages公開URL）を開きます。
2. 上部の **「🏋️‍♂️ クランクベンチ」** または **「📖 スタディROOM」** をタップして目的の店舗を探します（「📍 現在地」で最寄り順にもできます）。
3. 行きたい店舗の **「🍎 Appleマップでナビ」** ボタンをタップ。
4. iPhoneでマップアプリのルート案内が開始されます。
5. 車のCarPlayに接続すると、車のナビ画面に自動的に目的地までの案内が表示されます！

## 🛠️ ローカルでの起動方法

静的Webサイト（HTML/CSS/JS）として完全に自己完結しているため、サーバーなしでも動作します。

```bash

open index.html

# ローカルサーバーを起動する場合

# ブラウザで http://localhost:8000 を開く
```
