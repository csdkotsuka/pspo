# P・SPO 店舗マップ＆CarPlayナビ (P・SPO Navigator)

> **P・SPO（ピースポ）公式の店舗検索が使いづらい悩みを解消！**  
> 愛媛県内85店舗（全90店舗以上）を美しく高速なマップで一覧化し、**ローワーバックベンチ**や**スタディroom**のある店舗をワンタップで探せて、そのまま**Apple Maps / CarPlayでカーナビ案内を開始**できるオリジナルWebアプリケーションです。

---

## 🌟 主な機能・特徴

### 1. 🚗 スマホで開いてCarPlayでナビができる（Apple Maps連携）
- 各店舗カードやマップピンに、特大の**「🍎 Appleマップでナビ（CarPlay対応）」**ボタンを常時配置。
- iPhoneのSafari等でタップするだけで、即座にiOS標準「マップ」アプリが起動し、目的地への自動車ルート案内が始まります。
- 車の**CarPlay**にiPhoneを有線またはワイヤレス接続していれば、**車載ディスプレイにそのまま案内画面が投影**されます！
- ※ Google Mapsでの案内ボタンも併載しています。

### 2. 🏋️‍♂️ ローワーバックベンチ（背筋台）設置店舗を一発検索
- 指定の多機能自重背筋・体幹ベンチ（`img_machine_11.jpg`）が導入されている店舗（愛媛県内外 **17店舗**）をワンタップで絞り込み表示。
- スポットライトバナーと店舗カードに対象マシン画像つきでハイライト表示されます。
- **導入店舗例**: 松山本町店、松山空港通り店、松山湯渡店、松山中央通り店、南斎院店、砥部店＋ゴルフ、湊町2号店、伊予店、内子店、新居浜・松原店、大洲店、東予店＋ゴルフ、西条朔日市店＋ゴルフ、西条武丈店、SAUNA大街道店、旭川店、半田住吉店。

### 3. 📖 スタディroom（自習室・コワーキング）設置店舗を一発検索
- 24時間利用可能な集中個別ブース・Wi-Fi・電源・WEB個室を備えたSTUDY ROOMおよび自習カフェ併設店舗（**45店舗**）をワンタップで絞り込み。
- **導入店舗例**: STUDY ROOM 1, STUDY ROOM 2, 松大前店, 東温店, ジム&スタディカフェ大街道店, 千舟町店, 市駅南店, 愛大前店, 平和通り店, 姫原店, 三津店, 鷹子店, 西条武丈店, 新居浜松原店など。

### 4. 💼 会社設立・法人登記対応オフィス（P・SPO WORKS）を一発検索
- 「起業したい」「副業で法人登記したい」ビジネスパーソンのための、**住所利用・法人登記可能**な24時間ワークスペース。
- クイックフィルター **「💼 オフィス・登記」** ボタンから一発で絞り込み表示。
- **対応店舗**:
  - **P・SPO WORKS湊町店**: 松山市湊町4-5-6（伊予鉄「松山市駅」から徒歩約3分）
  - **P・SPO WORKS御宝店**: 松山市歩行町1-13-3（御宝ハイツ1F）
- **主な設備・特典**: 法人登記・専用郵便受けポスト・WEB個室ブース・共有複合機・Wi-Fi・電源・会議室完備。さらにP・SPO24各店舗のフィットネスジムも併せて利用可能！

### 5. 🏆 PSPO検定 対策クイズ（1年分会費無料を狙う100問完全攻略）
- 年1回開催される「PSPO検定」で上位入賞・満点を獲得し、**「1年分の会費無料」**を勝ち取るための本格対策機能！
- ヘッダーの **「🏆 検定対策クイズ」** ボタンからいつでもサクサク挑戦可能。
- **3つのモード**:
  1. **📝 模擬検定モード（10問ランダム）**: 全10ジャンルから1問ずつ本番さながらに出題。即時採点＆合否ランク判定（「神レベル！PSPOマスター」など称号つき）！
  2. **🎯 ジャンル別攻略モード**: 苦手なジャンルを集中的に10問トレーニング。
  3. **📖 100問完全問題集モード**: 100問すべての問題・選択肢・正解・詳細解説を一覧閲覧＆インクリメンタル検索可能！
- **収録全10ジャンル**: ユニーク店舗、温泉・サウナ、本格スポーツ、女性専用/美容、オフィス/登記、マシン/バイオ、地域展開、コラボ、利用ルール、三福グループの歴史。

### 6. 🗺️ 愛媛県内全域対応インタラクティブマップ
- **Leaflet.js** を採用した超軽量＆滑らかな地図表示。
- 松山市中心部、東温・砥部、西条・新居浜、今治・しまなみ、大洲・八幡浜・宇和島までピンポイント網羅。
- アイコン・カラー（🏋️ オレンジ=ローワーバックベンチ、📖 ブルー=スタディ、♨️ パープル=サウナ/温泉、💪 グリーン=ジム）で一目で判別可能。
- 「愛媛県全体」「松山市内」へのワンタップ表示切り替え機能。

### 5. 📍 GPS現在地連動 ＆ 距離順ソート
- 「📍 現在地」ボタンを押すだけで、今いる場所から最も近いP・SPO店舗を自動計算・近い順にソート。

### 6. 🔍 複合フィルター＆キーワード即時検索
- エリア別（松山、東温、砥部、今治、西条・新居浜、大洲・南予、県外）
- 設備・サービス別（セルフエステ・脱毛、サウナ・温泉・岩盤浴、シミュレーションゴルフ、カフェ、有人店舗）

## 📱 CarPlayでの利用手順

1. iPhoneのSafariで本アプリ（`index.html` または GitHub Pages公開URL）を開きます。
2. 上部の **「🏋️‍♂️ ローワーバックベンチ」** または **「📖 スタディROOM」** をタップして目的の店舗を探します（「📍 現在地」で最寄り順にもできます）。
3. 行きたい店舗の **「🍎 Appleマップでナビ」** ボタンをタップ。
4. iPhoneでマップアプリのルート案内が開始されます。
5. 車のCarPlayに接続すると、車のナビ画面に自動的に目的地までの案内が表示されます！

## 🛠️ ローカルでの起動方法

静的Webサイト（HTML/CSS/JS）として完全に自己完結しているため、サーバーなしでも動作します。

```bash
# ブラウザで直接開く場合（Mac）
open index.html

# ローカルサーバーを起動する場合
python3 -m http.server 8000
# ブラウザで http://localhost:8000 を開く
```
